# 视角选择

按待裁决的问题选职责不重叠的视角；候选库不要求全用。向用户简述所选视角各管什么。

| 视角 | 唯一负责的问题 |
|---|---|
| 长期价值 | 结果对长期目标有何价值，价值是否随时间变化？ |
| 机会成本 | 同样资源的最佳替代用途是什么？ |
| 时机节奏 | 立即行动或等待会增加哪些信息与选择？ |
| 工程可行性 | 成本、周期、依赖和最小实现路径是什么？ |
| 风险可逆性 | 下行、回退方式与对冲是什么？ |
| 证据质量 | 关键主张的证据、假设、已有方法与验证缺口是什么？ |
| 对抗审查 | 最强反方论证及能推翻当前判断的条件是什么？ |
| 历史一致性 | 是否违背仍有效的既有决定，是否重复劳动？ |
| 减法 | 满足目标的最小方案是什么？ |
| 受众与二阶效应 | 受影响者和激励会如何变化？ |
| 类比基准 | 可比场景有哪些结构性经验，适用边界是什么？ |

研究选题可从价值、机会成本、证据、反方及历史中选；工程取舍可从可行性、风险、反方、减法及受影响者中选。相近视角合并，只将必要原始材料交给对应视角。
